# SmartWeatherClock 智能天气时钟

基于 **STM32F407** + **ESP32-S3** 双 MCU 架构的智能天气时钟项目。

## 项目简介

- **STM32F407**：主控单元，负责 TFT 屏幕显示（GUI）、实时时钟（RTC）、本地传感器采集、按键/触摸交互、数据存储。
- **ESP32-S3**：无线通信单元，负责 WiFi 联网、获取网络天气数据、NTP 网络授时，并通过串口与 STM32F407 交互。

```
┌─────────────────────┐         UART          ┌─────────────────────┐
│      STM32F407      │ ◄───────────────────► │      ESP32-S3       │
│  · TFT 显示 / LVGL  │                       │  · WiFi 联网        │
│  · RTC 时钟         │                       │  · 天气 API 获取    │
│  · 传感器采集       │                       │  · NTP 网络授时     │
│  · SD 卡存储        │                       │  · JSON 解析        │
└─────────────────────┘                       └─────────────────────┘
```

## 后续需要添加的库（依赖清单）

### STM32F407 端（主控）

| 库/组件 | 用途 | 说明 |
| --- | --- | --- |
| STM32CubeF4 HAL / CMSIS | 基础外设驱动 | STM32F407 官方 HAL 库 |
| FreeRTOS | 实时操作系统 | 多任务调度（显示/采集/通信） |
| LVGL (v8/v9) | 图形界面库 | 天气时钟 UI 绘制 |
| TFT 驱动 (ILI9341 / ST7789) | 显示屏驱动 | 配合 LVGL 使用 |
| FatFs | 文件系统 | SD 卡存储天气历史/配置 |
| DS3231 / 内部 RTC | 实时时钟 | 本地时间保持 |
| DHT22 / BMP280 / SHT30 等 | 温湿度气压传感器 | 本地环境数据采集 |
| cJSON | JSON 解析 | 解析 ESP32 发来的天气数据（如由 ESP32 透传） |
| UART 通信协议 | 双机通信 | 自定义帧协议 |

### ESP32-S3 端（无线）

| 库/组件 | 用途 | 说明 |
| --- | --- | --- |
| ESP-IDF (v5.x) 或 Arduino-ESP32 | 开发框架 | ESP32-S3 固件基础 |
| ESP-NETIF / WiFi 驱动 | WiFi 联网 | STA 模式连接路由器 |
| esp_http_client | HTTP 客户端 | 请求天气 API（和风天气/OpenWeather 等） |
| cJSON / ArduinoJson | JSON 解析 | 解析天气 API 返回数据 |
| SNTP (esp_sntp) | 网络授时 | 获取 UTC 时间并校准 |
| UART 驱动 | 双机通信 | 与 STM32F407 串口交互 |

## 通信接口规划

- **硬件接口**：UART（默认 115200 8N1），可扩展 SPI/I2C。
- **数据方向**：
  - ESP32-S3 → STM32F407：天气数据、授时时间、联网状态。
  - STM32F407 → ESP32-S3：本地传感器数据、配置指令、请求命令。
- **协议格式**：自定义帧（帧头 + 长度 + 类型 + 载荷 + 校验）。
